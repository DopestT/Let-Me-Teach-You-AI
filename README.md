# Let Me Teach You AI

A beginner-focused AI education newsletter and digital-product business.

> We all got hit with AI at the same time. I decided I wasn't going to get left
> behind, so I started learning, testing, building, failing, and figuring out
> what actually works. Now I want to teach you what I know.

- **Canonical domain:** [letmeteachyouai.com](https://letmeteachyouai.com)
- **Secondary domain:** letmeteachyouai.net → permanently redirects (301) to `.com`
- **AI provider:** OpenAI (server-side only)
- **Email / newsletter:** Beehiiv

This is a standalone project. It shares **no** code, branding, data, or assets with
any other project.

## Stack

- Next.js 16 (App Router) · React 19 · TypeScript
- Tailwind CSS v4
- OpenAI official SDK (`openai`) — **server-side only**
- Beehiiv for subscriptions, the welcome sequence, and lead-magnet delivery
- Zod for input validation

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in your keys
npm run generate:pdf         # build the 25-prompt lead-magnet PDF
npm run dev                  # http://localhost:3000
```

## Environment variables

See [`.env.example`](./.env.example) for the full, commented list. The key ones:

| Variable | Purpose |
| --- | --- |
| `OPENAI_API_KEY` | OpenAI secret key. Server only — never exposed to the browser. |
| `OPENAI_MODEL` | Current OpenAI model (e.g. `gpt-5-mini`). Configurable, not hard-coded. |
| `NEWSLETTER_API_KEY` | Beehiiv API key. Server only — never exposed to the browser. |
| `NEWSLETTER_AUDIENCE_ID` | Beehiiv Publication ID (`pub_xxxxxxxx`). |
| `NEXT_PUBLIC_SITE_URL` | Canonical domain — drives metadata and the `.net`→`.com` + `www` redirects. |

Full deployment, domain, and DNS setup lives in [`DEPLOYMENT.md`](./DEPLOYMENT.md).

## Architecture notes

### OpenAI (secure, server-side)

- [`lib/openai/config.ts`](./lib/openai/config.ts) — single source of truth for the
  model and all limits, read entirely from env vars.
- [`lib/openai/client.ts`](./lib/openai/client.ts) — an `import "server-only"` client
  with a timeout, rate-limit awareness, and privacy-safe usage logging (counts and
  outcome only — **never** raw prompt content). Returns clear fallback messages when
  OpenAI is unavailable.
- [`app/api/openai/route.ts`](./app/api/openai/route.ts) — a validated, rate-limited
  endpoint. This is hardened **scaffolding** for future interactive lessons and
  prompt tools; there is no chat UI wired to it yet.

The OpenAI key is **never** imported into client components, and we do **not** send
subscribers' personal information to OpenAI.

### Newsletter + lead magnet

- Signups post to [`app/api/subscribe/route.ts`](./app/api/subscribe/route.ts)
  (validation, honeypot, rate limiting) → [`lib/newsletter.ts`](./lib/newsletter.ts),
  the provider-agnostic wrapper around Beehiiv.
- The 25-prompt PDF is generated by
  [`scripts/generate-lead-magnet.mjs`](./scripts/generate-lead-magnet.mjs) from
  [`content/lead-magnet-prompts.json`](./content/lead-magnet-prompts.json) into
  `public/lead-magnet/Start_Using_AI_Today_25_Beginner_Prompts.pdf`.
- The 5-email welcome sequence copy lives in
  [`content/welcome-sequence.md`](./content/welcome-sequence.md) — paste it into a
  Beehiiv automation triggered on new subscription.

### `.net` → `.com` + `www` redirect

Host-based 301 redirects are enforced in [`proxy.ts`](./proxy.ts) (Next.js 16 renamed
the `middleware` convention to `proxy`). It sends the `.net` domain (apex and `www`)
to the canonical host derived from `NEXT_PUBLIC_SITE_URL`. For production, we also
configure redirects at the Vercel domain level for reliability — see
[`DEPLOYMENT.md`](./DEPLOYMENT.md).
